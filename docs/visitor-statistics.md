# 首页公开访问统计

中英文首页底部使用同一个 Flag Counter，显示国家／地区、访客计数和累计浏览量，另有公开统计及地图链接。

## 首次启用

1. 打开 <https://flagcounter.com/>，选择 **Top Countries**。
2. 勾选 **Show Pageview Count**，生成计数器，完成验证码。邮箱注册可选；如需管理或排除自己的访问，可在服务方注册管理功能。
3. 保存生成的 HTML。把代码交给网站维护者，或将图片链接中的服务器名称和计数器 ID 填入 `_config.yml`。

例如，服务生成的图片地址若为 `https://s05.flagcounter.com/count2/AbCd/...`，配置为：

```yaml
visitor_statistics:
  enabled: true
  server: s05
  counter_id: AbCd
```

`AbCd` 仅为示例，必须使用服务实际生成的 ID；不要使用他人的计数器。计数器 ID 和服务器名称是公开的嵌入信息，不是管理密码。请勿在仓库提交邮箱、密码或登录凭据。

## 统计范围与显示

- 两种语言的首页各加载一次计数器图片，共享计数，其他页面不加载。数字反映首页访问，不能解读为全站页面浏览量。
- 图片使用即时加载，避免只有滚动到页底的访问才被计入。
- 仅生产环境加载，开发预览不增加计数。
- `counter_id` 为空或 `enabled: false` 时，整个统计区隐藏；不显示模拟数据或失效的占位图片。
- 从启用时开始累计，不能补算此前的历史访问。
- 地区根据服务方的 IP 地理库推算，VPN、代理、广告拦截和网络故障可能影响结果。
- Flag Counter 自行处理统计请求；网站仅嵌入其公开图片和详情链接，不使用浏览器精确定位。
